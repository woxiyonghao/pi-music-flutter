## 无安装孔的触控屏

官方触控屏总包络 **173×103×4.2，四角 R3**；外沿盖板厚 **0.70**。内缩 LCD 外形 **164×97**，金属部分 2.60，背部元件按 3.5 深包络保守避让。有效显示区 **154.2144×85.92**，竖向中心上移 2.35。LCD 横向相对盖板 -1.7 的摆位是两张图纸显示区对齐推算，背部实物仍需试装。

1. 一件式窄框 **190×120×8**，前开口 **168×98**，承托槽 **173.8×103.8**。前唇 1.4，黑边处贴约 0.4 厚软垫。玻璃前面在装配 Y=1.8，玻璃背面 Y=2.5；内缩 LCD 背部最大至 Y=6.0。不要把整片盖板当 4.2 厚。
2. 四只 M3 螺母从前框侧槽装入，对边槽 5.7、锚点 X=屏中心±91、竖向±25。螺丝全部在玻璃外轮廓之外；正面保留 1.8 实心壁。只锁打印件，不能打孔穿玻璃。
3. 后支架主体 Y=8..14，接触趾向前伸 3.5，趾面在 Y=4.5。每只接触趾贴约 **1×10×2.0** 的软垫，中心 X=屏中心±85.2、竖向±25；只夹外沿黑边，避开 LCD、排线及元件。支架打印朝向为后平面朝下、台阶朝上，已体现在 STL/3MF 中。
4. 每只支架外端配 M4×16 与螺母锁柱芯，内端配 **M3×12 + 0.5 厚平垫**锁框内螺母。支架靠打印框硬限位定位，通过软垫轻压玻璃。不得靠强拧把玻璃压弯；先手动试装，按实物微调软垫。
5. 下沿槽负责定位与承重；侧边可贴薄软垫消除游隙。屏幕后方中央留空，FPC 保持自然弯曲，不夹线。

HDMI 转接板是独立 PCB：**50×25.5，四孔距44.7×20.2，原板孔径2.75**。它的孔不是玻璃安装孔。托盘通孔2.8，台面3+支柱6=9高，M2.5螺母槽深3.0。配4套 M2.5×10 与名义2厚螺母，无额外垫片；PCB厚1.6为装配假设，实物异常时须重算长度。HDMI/USB-C朝后，FPC朝屏幕，ON/OFF开关可达。

官方资料：[微雪参数](https://docs.waveshare.net/70H-1024600/) · [微雪图纸](https://docs.waveshare.net/70H-1024600/Resources-And-Documents/)。图纸保存在 `reference/`。

## 机架与设备

外形约 **268×266×463**（含柱壳、侧板与底脚），层板本体 **260×244×8**。自下而上净高：**ZA3 90、DX1 II 85、屏幕/树莓派/硬盘150、空置预留层90**。每层两块130×244半板，侧板分层打印。

- 前后四根立柱统一32宽、4倒角的分段外壳，接片和多余孔位内藏，每段两颗内凹螺丝。**各层背部均敞开**，仅保留必要结构横条，没有后挡板。
- 树莓派带套餐的**黑色 ABS 壳**固定在左内壁：散热面朝内，USB-C电源向上，网口/USB朝前屏幕，按键端朝开放后方。不是红白官方塑料壳。当前占位 **前后长100×竖高70×厚35**；电源插头区Y=180..210、顶部以上22为保守假设。
- 带保护壳硬盘固定在右内壁，占位 **竖高125×前后80×厚20**。两边设备均用两个下托和两个上限位钩，沿长槽调节并贴软垫。插头与线材在架内；实际接口与线弯曲空间待测。
- 屏幕层→DAC层、DAC层→ZA3层的两块隔板，各有 **68×38、R9** 穿线孔。孔口须检查是否容纳你实际插头，并在接触处贴护边。
- **DX1 II** 官方尺寸为100×100×32（含突出部分），已与用户确认型号对应。可在本层居中或向前放；没有为其添加不存在的独立DC圆口。官方USB-C同时用于USB输入与供电，前后面板细节仅示意。[官方说明书](https://dl.topping.audio/um/DX1_II_V1.1_CN.pdf)，本地保存于 `reference/DX1_II_V1.1_CN.pdf`，第26页。
- **ZA3** 保持184×184×51的保守方形包络。厂家给出154.9×183.9×50.8数值，宽深轴未用零售商互相冲突的标法硬定；方形留位涵盖两种平面方向。预览位置后面距层板边32，不保证能包住直头XLR/RCA/香蕉插及弯折。其侧面散热口不能被贴紧遮盖；需真实插线和温升验证。[厂家产品页](https://fosiaudio.com/products/fosi-audio-za3-balanced-dual-mode-class-d-amplifier)。
- 顶层为空托盘，不包含CD机。Sony D131未建立实测包络。
- 丢失按键帽仍缺壳孔宽高、卡扣/凸缘、壁厚及推杆行程，**尚无匹配该黑壳的按钮STL**。

## 线材与供电

视频线是 **树莓派Micro HDMI → 转接板标准HDMI**，不是Micro USB。触摸/屏幕供电走转接板Touch USB-C与主机USB连接；弯头方向要用实际安装方向试插。[微雪接线教程](https://docs.waveshare.net/70H-1024600/Development-Adapter-User-Guide/)

DX1 II额定输入5V/1.0A、典型正常功耗2.5W；微雪要求5V且供电能力大于500mA；硬盘启动峰值未知。树莓派5识别5V/5A电源时，下游USB总限流为1.6A，且预算与风扇共用；普通3A电源时为600mA。**当前不能保证屏幕+硬盘+DAC全部由Pi同时供电。** 先桌面接齐验证，按实际功耗选合规独立供电/有源USB方案并保留空间，不能只看电源标有5A就认定每个USB口都有5A。ZA3使用其独立电源。[树莓派官方供电说明](https://www.raspberrypi.com/documentation/computers/raspberry-pi.html)

## 螺丝与装配

用户套装有M3/M4大扁头机牙、自攻、螺母及垫片。本模型采用**机牙螺丝+螺母**；不要把自攻螺丝拧进螺母。M4通孔4.5、头孔9.4，按图中头径约8.5留径向0.45间隙。**头高未知**：层板头槽3.0、侧板2.1、柱壳3.0，不保证实际头能完全沉入。常规M4螺母槽对边7.5/深3.4，底脚深4.5为局部例外。真实螺母对边、厚度与垫片须先试。

先打印试装片：第一排孔径3.2/3.4/4.2/4.5；第二排头孔直径8/9/10/11、深3.5。不要整体缩放全部模型来补偿螺丝孔。

| 五层板中央及前后连接片 | M4×12 | 80 |
| 16根柱芯上下承台 | M4×12 | 32 |
| 8块侧板到柱芯 | M4×12 | 32 |
| 16件柱壳，兼夹紧12块隐藏跨层接片 | M4×20 | 32 |

| 四只屏幕后支架到柱芯 | M4×16 | 4 |

合计M4螺丝/螺母各192、M3各6、M2.5各4，另4片0.5厚M3平垫。柱壳32套里24套兼作隐藏接片紧固，不重复计数。用户盒中M2.5未见，需另备；各规格数量未知，可能需补充。

名义长度核对覆盖全部202处连接：M4共192、M3共6、M2.5共4。螺杆与当前打印件及设备包络无碰撞，名义螺母完整咬合。屏框盲孔、小板及底脚等12处另核对了尖端余量，其余贯通孔采用开放尖端的几何检查。未模拟真实螺纹、扭矩、真实头高或材料强度；头型、垫片、螺母厚度改变时须重新核对。

顺序：螺丝试装片→壳/硬盘托钩→底板与底脚→逐层柱芯/侧板/层板→隐藏接片→屏幕层小板与内部设备→窄框/软垫/后支架→穿线试机和触控→最后四柱壳及顶盖。屏幕内部支架先装好再封柱壳。

## 打印机与手机

照片只能推测P1S，无法仅凭AMS 2 Pro确认机型、喷嘴或耗材。参考工程：P1S/0.4喷嘴/Generic PETG/纹理PEI/0.20层高/5圈墙/30% gyroid/无支撑；属于参考假设。小槽桥接和屏幕接触趾先试印。

文件格式为 **.3mf**，不是.msf。Handy/MakerWorld直接打印依赖匹配机型及有效切片配置。此包不是已匹配你实机的一键任务；在Bambu Studio核对机型、喷嘴、耗材与板型，试装后再切片发送。没有控制打印机、上传或公开模型。`validation/VALIDATION_ONLY_*.gcode.3mf`仅用于参考验证，不是最终实机指令。
